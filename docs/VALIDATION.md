## 本轮新增覆盖

- SQLite 只读导入保持原文件不变，PostgreSQL 密文与旧库字节完全相同，重启不重复导入。
- 核心精神正文不出现在 PostgreSQL 密文明文扫描、业务导出或 Agent 上下文中。
- PostgreSQL 审计故障会回滚精神快照；审计拒绝修改、删除和清空。
- 签名覆盖正文与路径；错误私钥、超时请求、篡改正文、替换路径、重复随机数均拒绝。
- 已消费签名在服务重启后仍不可重复使用。
- 只读授权只返回选中的当前条目，没有历史；接收者不能修改、复核、发布、继续授权或读取业务导出。
- 授权绑定公钥，锁定暂停读取，撤销和到期立即拒绝；请求中加入写权限字段被拒绝。
- 浏览器创建设备公钥、创建只读授权、撤销授权通过；只有 cookie、没有签名的直接 API 读取被拒绝。
