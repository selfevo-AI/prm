### 本轮新增覆盖

**本体与 Agent 接入（接入即关系）**
- `ai_agent` 类注册到数字界；`involves` 扩展到 AI Agent；`from_agent` 谓词属于来源追溯层且不可由本人手工建立；`sync_sql` 包含新类与新谓词（单元）。
- `POST /api/agents/connections` 带 `platform`、`relationship_type`、`scenes`、`notes` 时：登记 `ai_agent` 实体（世界、平台、场景正确），建立 `relationship`（`party_kind = ai_agent`、`agent_name`、场景），自动建立 `involves` 与 `relates_to_self`，返回令牌与接入片段；用该令牌导入后，导入记录带 `agent_entity_id` 并通过 `from_agent` 关联到 Agent；连接列表携带平台、场景与关系编号，并提供平台预设与 AI 关系类型（集成）。
- 非法平台、非 AI 关系类型、空名称、非法接入方式均 400；人物关系流程拒绝 `ai_*` 类型；仅 `name + protocol` 的旧式签发保持兼容（集成）。
- 平台预设 id 唯一、`custom` 可用、片段含令牌与协议形状；AI 关系类型列表、默认场景与对方名称解析（单元）。

**界面与国际化（浏览器）**

### 本轮新增覆盖

**本体注册表（单元）**
- 类与谓词标识唯一、SQL 安全；谓词签名只引用已注册的类；非本人可建立的关系（derived_from、records、receives、pays 等）不可通过 `/api/relations` 建立；场景校验与默认值。

**自我本体**
- 量表目录内部一致性（指标编号与范围唯一）；BPNSFS 分量表按范围录入、超范围拒绝；指标不属于所选量表时拒绝；同一指标重复填写拒绝；观察时间校验；未知字段 422。
- 自定义指标单值约束；“旧版自评”记录保持可读。
- `describes_self` 关系自动建立；Agent 可见性开关与版本冲突（409）。
- 核心原则上下文与 `/api/self/agent-preview` 只包含本人标记可见的自我记录；`PRIVATE-CORE` 与隐藏记录在预览、导出、工作区与 Agent 上下文中均不出现。

**关系网络**
- 人物与关系的创建校验（类型、亲密度 1–7、满意度 1–5、联系节奏）；`involves` 与 `relates_to_self` 自动建立。
- 互动流水只追加、更新最近联系日期；未来日期拒绝；重复提交因版本冲突拒绝。
- 超过联系节奏时生成“联系：…”建议且同一版本只生成一次；暂停关系后不再生成；采纳后任务继承关系场景。

**Agent 网关与路由**
- 连接令牌只存 SHA-256、只显示一次、可撤销；撤销后立即 401。
- 令牌只能导入与查询自己的导入状态；读取工作区、导出、核心原则、执行器接口均 403；其他连接的导入 404；含未知字段的导入 422。
- 模型地址必须为回环 http（`https`、远程主机、带用户信息、非法端口等全部拒绝）。
- 路由按优先级匹配场景；模型停用后回落到离线规则并在导入记录中说明。
- 执行器租约：错误租约 409；重复提交 409；失败重试 3 次后标记失败并同步导入状态；未通过本体校验的候选被拒绝并在结果中给出原因。
- 外部导入的资源与关系只有在本人采纳后才写入本体（`derived_from` 溯源）；引用同批候选的关系需先采纳被引用项（否则 409）。

**PRP**
- 物料主数据默认值、库位与供应商关系（`stored_at`、`supplies`、`located_in`）。
- 采购订单：草稿加行并自动累计金额；无行不可下单；下单后不可再加行；重复收货因版本冲突拒绝；超量收货、超付、已收货取消均拒绝；收货生成入库流水并回写已收数量与订单状态；付款生成带 `pays` 关系的现金流水；完结后不再收货付款。
- 出入库方向与类型必须一致；盘点调整两个方向均可过账。
- 低库存建议包含补货量、供应商与交货周期；资产保修 30 天内生成“保修检查”建议且不重复。

**浏览器（两条流程）**
- 流程一（原有回归）：账户建立、演示数据、思维条目与本人确认、只读授权创建与撤销、执行方向发布与撤回、消息与建议采纳、任务完成、库存出入库与限制、现金、本体关系、版本历史、导出不含私密内容、退出与重登；360/390/768/1440 像素无横向溢出。
- 流程二（新增）：RSES 得分录入与趋势显示；“我是……”自我认同与 Agent 可见预览不包含私密内容；人际关系的创建、互动记录与最近联系；签发 Agent 令牌并用独立 HTTP 客户端导入（工作区读取 403）；导入候选采纳为资源实体；供应商与采购订单（加行 → 下单 → 收货 → 付款 → 完结）；现金流水与库存数量核对；人生场景全局筛选；新增页面在 390 像素宽无横向溢出。

**既有安全回归（22 项全部保持通过）**
- 核心精神加密与重认证、只读授权绑定/撤销/锁定敏感、签名重放与篡改拒绝、会话限速、审计不可改、旧 SQLite 迁移幂等且原文不变、单工作区锁、跨站与 DNS 重绑定拒绝。

### 未覆盖与限制

- 本地模型执行器尚未对接真实模型端到端验证（本机未安装 Ollama 或 OpenAI 兼容服务）。协议本身（领取、租约、结果校验、失败重试）已由 Rust 集成测试覆盖；调用真实模型的路径需按所选模型另行验证。
- MCP 工具桥为结构实现（JSON-RPC over stdio），未在真实 MCP 客户端中联调。
- 0.4 启动时为既有工作区补充 `scenes` 列并同步本体约束（幂等 DDL），本轮以空库与旧 SQLite 合成数据验证；本人真实工作区未代其解锁或写入。
- 外部 TLS、硬件认证、多设备同步、真实模型推理质量、独立安全审计和大规模并发仍不在验证范围内。
