# 自我本体：资源与关系

自我本体是 PRM 的锚点：R 既指本人可调用的身心资源，也指本人与外界、与自我的关系。所有记录都由本人填写、本人解释、本人决定是否让本地模型读取（默认不可读取）。它们是**观察，不是诊断**；系统不会把不同量表或指标合成为单一的幸福或健康分数，也不内置临床筛查量表。

## 四类自我记录

| 类 | 内容 | 依据 |
| --- | --- | --- |
| 生理自我指标 `body_metric` | 睡眠、心血管、体成分、身体活动、主观体感（NRS） | 本人记录或设备读数 |
| 心理自我认定 `psychological_metric` | 主流心理学量表的总分或分量表分 | 见下方量表目录 |
| 自我认同 `identity` | “我是……”陈述，按身体特征 / 社会角色 / 心理特质 / 整体存在归类，标注重要程度 1–5 | 二十句陈述测验 TST（Kuhn & McPartland, 1954, *American Sociological Review*, 19(1), 68–76） |
| 自我关系 `self_relation` | 对自己的立场：自我接纳、自我关怀、自我苛责、自我信任、理想自我、应然自我、自我边界、成长意图 | Ryff（1989）心理幸福感中的自我接纳；Neff 自悯理论；Higgins（1987）自我差异理论（*Psychological Review*, 94(3), 319–340） |

与他人的关系另见“关系网络”：人际关系记录类型、亲密度（IOS）、满意度（RAS）和联系节奏，互动按事件追加。

## 可见性与核心原则

本地模型处理外部导入时，以本人发布的执行方向为核心原则，以本人逐条标记为可见的自我认同、自我关系、指标最新值和人际关系为背景。任何记录都可以随时切换为“仅本人”，下一次路由立即生效。“自我本体 · Agent 可见预览”展示模型实际收到的全部内容。
